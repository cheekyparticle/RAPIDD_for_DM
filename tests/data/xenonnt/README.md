# XENONnT limit (verbatim copy of the data release)

`XENONnT_SR012_s2_only_wimp_electron_qedark_after_pcl_limit.csv`: S2-only DM-electron limit, heavy mediator (QEDark
form factors), 90% CL after the power constraint, from the
[s2_only_data_release](https://github.com/XENONnT/s2_only_data_release) (arXiv:2601.11296). It is the same limit as
`lib/experiments/XENONnT/XENONnT_DMe_SI.dat` used by MadDM, and is used by `examples/evaluate_ER_rates.ipynb` and
`examples/checks_ER_rates.ipynb`.
